Dyscharged

2.5D RPG | Unreal Engine 5 | Blueprints | C++ | Scrap Metal Studios

Project Overview

Dyscharged is a 2.5D post apocalpytic RPG currently being developed by a team of 10.

Developed Features

  • Primitive Foundation for Dialogue in C++
  • Item Interaction
  • Data-driven dialogue system; data comes from table

C++ Talk Function

When the Input action, F, for "Talk" is pressed, the function runs. It checks if the player is in range to talk to an NPC, and if it does, the logic continues.

Dialogue Blueprint Logic

Event Show and Event Update Questions are custom defined events in the customized C++ class for this Widget Blueprint.
