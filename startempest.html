    • Player Mounting Vehicles

    Result:

    How it works:

  • When the player lands, line trace goes down 500 pixels.
  • It looks for object of type "Hovecraft."
  • If it finds one, it gets its variable "E_MountType," which is Triceratops, Hovercraft, or Snowboard.
  • If it's Hovercraft or Snowboard, it executes an interface message to set pawn class to Hovercraft or Snowboard respectively.
