How it Works

Here's how the submarine periscope simulation works.

  • Reads "Data Table" information based on developer defined data structure.
  • Data Table information places the "Explanation" text onto the screen.
  • If both boolean variables "bIsVoiceLine" and "bShowPrompt" are false, and enumeration E_SuccessCheckType is "None," the simulation requires a user input to proceed. This is the "Required Key" variable, and it waits for the user to press that key.
  • If it's valid, the simulation plays the sound variable placed in "VoiceLine."
  • If "bShowPrompt" is true, the simulation displays a prompt on the screen, reading "Press Any Key to Continue."
  • Enumeration E_SuccessCheckType is important for the interaction tutorial step, this could be changed if the simulation project were to continue and designers needed alternative success checks.
  • If "bPressAnyKeytoContinue" is true and "bShowPrompt" is true, when the prompt reading "Press Any Key To Continue" appears, the user can press any keyboard button to progress in the simulation.
  • The "Required Actor" is important for the interaction tutorial step. It checks if the actor is present in an array of actors stored in the Game Instance--this indicates the actor has been interacted with.
