MOV to MP4 Converter

Python | Visual Studio

Project Overview

IDE used was Visual Studio 2022. Application takes mov files and converts them to mp4 files.

GitHub link below.

GitHub Link

Used Libraries

How it Works

Users input file paths in both input and output folders.

Failsafe - Create Output Folder

If the output folder doesn't exist, the os.makedirs(output_folder, exist_ok=True) line handles creating the output folder.

Get all .mov files

mov_files = [f for f in os.listdir(input_folder) if f.lower().endswith(".mov")]

For Loop -- For each file found in the input folder, convert it into mp4, and then give it the proper extension

for filename in tqdm(mov_files, desc="Converting videos", unit="video"):

input_path = os.path.join(input_folder, filename)

output_filename = os.path.splitext(filename)[0] + ".mp4"

output_path = os.path.join(output_folder, output_filename)

Show progress bar when converting files

try:

with VideoFileClip(input_path) as video:

total_frames = int(video.duration * video.fps)

Actual conversion from mov to mp4

video.write_videofile(output_path, codec="libx264", fps=video.fps)

Throw an error if any clips fail to convert

except Exception as e:

print(f"\n Error converting {filename}: {e}")
